# 반복 1 검증 — 페르소나 셀프 테스트 프로토콜

> 방식: 본인이 페르소나 **김성균(21, 율전캠 2학년, 명륜 축제 후 귀가)** 이 되어
> 시나리오를 수행하고 측정한다. (조교님 가이드: 주변인 테스트 대신 페르소나 테스트)

## 검증할 가설 (H1)

시간·장소가 구조화된 팟 보드는 에브리타임 자유 글보다 동승자 매칭 과업을 빠르고
확실하게 만든다.

## A. AS-IS 기준선 측정 (에브리타임 방식)

### A-1. 과업 시뮬레이션 (본인 수행, 초시계 측정)
1. 에브리타임 글 작성 화면을 열고 실제 구인 글 초안을 작성한다 (게시는 안 해도 됨).
   - 측정: 글 작성 소요 시간, 포함해야 하는 정보를 빠짐없이 쓰는지 (탑승 장소/시간/하차/인원)
2. 댓글→쪽지 조율 과정을 단계로 나열한다 (글 작성 → 댓글 대기 → 쪽지 → 시간 합의 → 장소 합의 → 만남).
   - 측정: 총 단계 수, 각 단계에서 실패(잠수·불일치) 가능 지점 수

### A-2. 관찰 데이터 수집 (데스크 리서치)
에브리타임에서 과거 택시 동승 구인 글 5~10개를 찾아 기록:

| # | 글 작성 시각 | 첫 댓글까지 | 인원 성사 여부 | 비고 |
|---|---|---|---|---|
| 1 | | | | |

→ "첫 댓글까지 평균 N분, 성사율 M%"가 AS-IS 기준선이 된다.

## B. TO-BE 측정 (택시팟, https://taxipot00.vercel.app)

각 시나리오를 페르소나 관점에서 수행. **초시계로 시간 측정 + 마찰점 즉시 메모.**
참여자 역할은 시크릿 창(또는 다른 기기)으로 수행한다.

| 시나리오 | 상황 | 성공 기준 |
|---|---|---|
| S1 팟 개설 | 밤 11시 혜화역, 성대역 방향 팟을 연다 | 60초 이내 개설 완료 |
| S2 팟 참여 | 동승자 입장: 조건 맞는 팟을 찾아 참여 | 30초 이내 참여 완료 |
| S3 조건 불일치 | 수원역 방향인데 맞는 팟이 없음 | 필터 확인 후 막힘 없이 개설로 전환 |
| S4 정원 마감 | 시크릿 창으로 인원을 채워 마감시킴 | 마감 표시·추가 참여 차단 확인 |
| S5 공유 | 팟 링크를 복사해 에타 글 초안에 붙임 | 링크 복사 1탭 + 붙여넣기 정상 |

## C. 판정과 다음 가설

- **H1 판정**: TO-BE 과업 시간/단계 수가 AS-IS 시뮬레이션·관찰 기준선보다 유의미하게
  짧으면 채택. (예: 개설 60초 vs 에타 글 작성 3분+대기 N분)
- **다음 가설 도출**: B의 마찰점 목록에서 가장 자주/크게 걸린 것이 반복 2의 입력이 된다.
  - 정산 관련 마찰 → H2(1/N 정산 도우미) 그대로 진행
  - 신뢰/유동성 마찰 → H3 후보를 앞당김
- GA4 이벤트(pot_create/pot_join/pot_full)와 Supabase 타임스탬프가 수행 기록의
  객관적 증거로 남는다 — 발표 자료에 캡처로 활용.
