> 이제: 팟 페이지에 총액 입력 → 인당 금액 자동 계산 → 동승자 화면에
> "토스로 12,667원 보내기" 버튼이 뜬다.

## 반복 3 방향 (데이터가 결정)

두 반복에서 **모두** 발견된 유일한 마찰은 "페이지를 닫으면 정보 단절"(알림 부재)이고,
반복 2에서 새로 드러난 구조적 한계는 "기기 기반 식별"이다. 발표 스토리라인 기준:
- 신뢰·연속성이 서비스 성패를 가른다고 보면 → **H3-a (학교 이메일 인증)**
