## AS-IS 비교 (에브리타임 방식 시뮬레이션)

에타 구인 글 초안 작성 재현: *"11시 40분쯤 혜화역에서 성대역 가실 분 2명 구해요.
택시 같이 타요! 댓글이나 쪽지 주세요"* — 작성 자체 약 1~3분.

| | AS-IS (에타) | TO-BE (택시팟) |
|---|---|---|
| 과업 단계 | 6단계 (글 작성→댓글 대기→쪽지 왕복→시간 합의→장소 합의→만남) | 4단계 (필터→선택→닉네임→참여) |
| 소요 시간 | 글 작성 1~3분 + 첫 반응 대기 10~40분(문제정의 시 경험치) + 조율 | **1분 이내** (맞는 팟 존재 시) |
| 실패 지점 | 3곳 (무반응·조건 불일치·잠수) | 1곳 (맞는 팟 없음 → 개설로 즉시 전환 가능) |
| 조건 확인 | 글마다 읽고 해석해야 함 | 시간·장소·인원이 구조화되어 한눈에 |

## H1 판정: ✅ 채택

구조화된 팟 보드는 동승 매칭 과업의 단계 수(6→4)와 소요 시간(수십 분→1분 내),
실패 지점(3→1)을 모두 줄인다. 단, "맞는 팟이 존재할 때" 이야기 — 팟 유동성이
없으면 가치가 성립하지 않는다는 한계도 확인 (→ 반복 3 후보 가설과 연결).
